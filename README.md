# Cosmos ❤️ API

API backend pour l'application Cosmos (rencontre astrologique).

## Endpoint

POST /inscription

## Données attendues

- prenom
- email
- mot_de_passe
- date_heure_naissance
- ville_naissance

## Réponse

Retourne :
- soleil
- lune
- ascendant
- latitude
- longitude
- compatibilite
